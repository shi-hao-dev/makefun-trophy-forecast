A deterministic Python forecaster for GTA VI (PS5) trophy earn rates on Exophase: it models earners and tracked players separately in logit space, so Exophase refresh dilution and player progression are both priced in, and blends in each trophy's own fitted rate trend when the case history shows one.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
